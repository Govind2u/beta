# Beta Processor

A processor design project developed using **Verilog HDL** and **Xilinx Vivado**.

## Overview

This project focuses on the design, simulation, and implementation of a Beta Processor using digital hardware design concepts. The project explores processor architecture, instruction execution, and hardware description using Verilog HDL.

## Tools & Technologies

- Verilog HDL
- Xilinx Vivado 2022.2
- Digital Logic Design
- FPGA Design and Simulation

## Project Structure

| Folder/File | Description |
|---|---|
| `beta processor.cache` | Vivado cache files |
| `beta processor.hw` | Hardware-related files |
| `beta processor.ip_user_files` | IP-related generated files |
| `beta processor.runs` | Synthesis and implementation files |
| `beta processor.sim` | Simulation files |
| `beta processor.srcs` | Source code and design files |
| `beta processor.xpr` | Vivado project file |

## Getting Started

### Requirements
- Xilinx Vivado Design Suite
- Basic knowledge of Verilog HDL
- FPGA development environment

### Setup Instructions

1. Clone this repository.
2. Open Xilinx Vivado.
3. Select **Open Project**.
4. Locate and open `beta processor.xpr`.
5. Explore the Verilog source files.
6. Run simulation and synthesis to verify the design.
